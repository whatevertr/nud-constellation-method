# exemplo-revisar-texto

*Skill de exemplo. Pra tirar, peça pro thinker mover esta pasta pro `_to_delete\` da galaxy.*

1. Leia o texto inteiro antes de sugerir qualquer coisa.
2. Corrija a grafia e a pontuação; marque à parte o que é escolha de estilo.
3. Devolva o texto revisado e, embaixo, a lista do que mudou e por quê.
