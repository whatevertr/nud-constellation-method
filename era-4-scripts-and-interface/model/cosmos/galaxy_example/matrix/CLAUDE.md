# matrix: as skills desta galaxy
- `skills_context\`: skills que **injetam contexto** (o que a compactação perde e precisa voltar: o jeito da pessoa, um projeto, um glossário).
- `skills_craft\`: skills que **fazem um trabalho** (um tipo de documento, uma análise, um fluxo).
- A fonte de cada skill mora aqui; as casas ligam a skill por junção (atalho de pasta), sem cópia.
