# galaxy_example
*Uma galaxy = um universo de trabalho (ex.: o pessoal, o trabalho, um projeto criativo), com um Tars só. Renomeie a pasta e este título.*

- **Ferramentas desta galaxy:** `tools\` (`registrar.py`, `leitor.py`, os hooks, `fatiador.py`, `buscador.py`). Rodar sempre com o Python desta máquina: `{PYTHON}`
- **Estrutura:** `station\` (as casas: um `module_` por agente) · `missions\` (o trabalho; cada mission tem `CLAUDE.md` com cabeçalho + `log.jsonl` + `lab\`) · `matrix\` (`skills_context\` e `skills_craft\`) · `_to_delete\` · `_archived\`.
