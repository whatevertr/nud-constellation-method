# nud-agentes

Skill que entrega os três perfis de agente do Método Constelação, `thinker` (pensar/analisar), `manager` (conduzir/auditar) e `worker` (executar/operacionalizar), e ajuda a configurar o escolhido na sua plataforma.

## Instalar

Copie a pasta `nud-agentes/` inteira para o diretório de skills da sua instância (ex.: `.claude/skills/` no Claude Code) ou instale pela interface. A skill é lida a partir de `SKILL.md`; os três perfis ficam em `modelos/`. Não apague a pasta.

## O que tem dentro

- `SKILL.md`: o passo a passo (entende o que você precisa, entrega o perfil, ajuda a configurar, testa).
- `modelos/`: os três perfis, prontos para usar.

## Complementa com

`nud-como-trabalhar-comigo` (o manual, sobre a pessoa) e `nud-comece-aqui` (a porta, sobre o projeto). Pra instalar o método inteiro, `nud-install-constellation-method`, na raiz do repositório.
