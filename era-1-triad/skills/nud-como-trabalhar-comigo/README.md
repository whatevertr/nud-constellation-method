# nud-como-trabalhar-comigo

Conduz a entrevista das 7 dimensões de perfil (motor anti-interpretação: a
pessoa responde uma letra, a instância cola a frase exata) e entrega o
`how_to_work_with_me.md` — o MANUAL da Tríade de Contexto, base científica
em psicologia cognitiva.

## Instalar

Copie a pasta `nud-como-trabalhar-comigo/` inteira para o diretório de
skills do seu agente (ex.: `~/.claude/skills/`). Estrutura:
`SKILL.md`, `LICENSE`, `referencias.md`, `modelos/how_to_work_with_me.md`,
`regras/perguntas_e_frases.md`, `regras/regras_de_preenchimento.md`.
