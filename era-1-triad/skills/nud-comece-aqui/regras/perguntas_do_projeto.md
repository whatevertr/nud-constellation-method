## Perguntas da PORTA (`start_here`) — sobre o PROJETO
*São 3 perguntas abertas, **uma de cada vez**, em texto normal (nunca as três de uma vez). Os TÍTULOS abaixo (objetivo prático etc.) são **INTERNOS** — servem só para você saber onde encaixar a resposta no `start_here`. **NÃO mostre o título para a pessoa; faça só a pergunta.***
- **→ objetivo prático** *(interno)* — pergunte: *"O que a gente vai construir, em concreto? (ex.: um site para a empresa X, no formato Y, até quando)"*
- **→ fundamentação teórica** *(interno)* — pergunte: *"Que bases de conhecimento esse trabalho exige levar em conta? (áreas, referências, restrições técnicas ou normativas)"*
- **→ objetivo abstrato** *(interno)* — pergunte **só**: *"Por que esse objetivo é importante?"* — sozinha, **sem exemplo**. A pessoa responde livre; você usa a resposta para preencher o objetivo abstrato, não existem regras, o motivo pode ser qualquer um.
