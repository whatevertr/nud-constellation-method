# nud-comece-aqui

Skill que conduz a conversa sobre um PROJETO (3 perguntas abertas, uma de cada vez) e entrega o `start_here.md` preenchido — a PORTA de contexto que orienta uma instância de IA sobre onde está entrando.

## Instalar

Copie a pasta `nud-comece-aqui/` inteira para o diretório de skills da sua instância (ex.: `.claude/skills/` no Claude Code). A skill é lida a partir de `SKILL.md`; `modelos/` e `regras/` são consultados por ela — não apague nenhum dos dois.

## Complementa com

`nud-como-trabalhar-comigo` (perfil da pessoa) e `nud-agentes` (papéis worker/thinker/manager).
